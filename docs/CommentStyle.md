# C# 주석 작성 규칙

## 선언부

클래스, 인터페이스, 레코드, 구조체, 열거형, 생성자, 함수와 속성은 XML `summary`를 사용한다.
설명 본문은 정확히 두 줄로 작성한다.

```csharp
/// <summary>
/// 현재 맵의 UI 선택 상태 노출
/// 지도 선택 바인딩과 내부 상태를 같은 값으로 유지
/// </summary>
public bool IsSelected { get; set; }
```

- 첫 번째 줄: 선언의 목적
- 두 번째 줄: 해당 선언이 필요한 이유
- `합니다`, `입니다`, `됩니다` 등의 서술형 종결어미 제외
- 마침표 제외
- 식별자만 반복하는 설명 대신 처리 대상과 결과 명시

## 함수 내부

함수 내부의 주요 단계, 비정상 경로, 성능상 중요한 처리에는 `//`를 사용한다.

```csharp
// 손상된 SEN 하나가 전체 병합을 중단하지 않도록 파일별 읽기 격리
foreach (var path in paths)
{
    // ...
}
```

- 코드 한 줄을 그대로 번역하는 주석 제외
- 왜 해당 분기나 순서가 필요한지 설명
- 빈 `//` 구분선 제외
- 구현이 바뀌면 주석도 같은 변경에서 갱신
